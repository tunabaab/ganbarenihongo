# 頑張れ頑張れ日本語 · 간바레간바레니혼고

일본어 입문 스터디원 전용 학습 사이트입니다. (스터디원 외 이용 불가 · 공용 비밀번호 필요)

- 단어장 (내장 사전 검색, 한글 발음 → 히라가나 변환, 히라가나·가타카나 자판, 플래시카드)
- 문형장 (반말/존댓말/공통)
- 단어 테스트 (뜻 고르기 · 일본어 고르기 · 동사 구분 · 비슷한 발음 짝 맞추기, OX/3·4·5지선다)
- 문형 테스트 프롬프트 만들기 (Claude·ChatGPT용) → 오답노트 자동 정리
- 메모 · 댓글, 엑셀 내보내기 · 백업/되살리기, 사용 가이드

## 구성
- `index.html`, `css/`, `js/` : 사이트 (GitHub Pages로 배포)
- `js/config.js` : Supabase 주소와 **공개(publishable) 키** — 공개되어도 되는 값입니다. secret 키는 절대 넣지 마세요.
- `supabase/` : 데이터베이스를 처음 만들 때 실행한 SQL (01 → 02 → 03 순서)

## 자료 이용 안내
이 저장소에는 사이트 코드만 있으며, 스터디원이 입력한 학습 자료는 비밀번호로 보호된 데이터베이스에만 저장됩니다.
학습 자료는 스터디원의 비영리 개인 학습용이며, 교재 내용의 저작권은 해당 출판사·저자에게 있습니다. 상업적 이용·외부 공개·무단 배포를 금지합니다.
